# API Endpoints

## Auth

- `POST /api/auth/login`

## Catálogo

- `GET /api/catalog`
- `POST /api/catalog/services`
- `POST /api/imports/excel`

## Clientes

- `GET /api/clients`
- `POST /api/clients`

## Cotizaciones

- `GET /api/quotations`
- `POST /api/quotations`
- `PATCH /api/quotations/:id/status/:status`
- `POST /api/quotations/:id/pdf`

## Pipeline

- `GET /api/pipeline/kanban`

## Auditoría

- `GET /api/audit/quotation-history`

## Métricas

- `GET /api/metrics/dashboard`
